## 📌 项目定位
MorningBriefAgent 是一个专为个人高效信息获取、日程/待办规划及个人健康/生活管理量身打造的 AI 智能助手。

本项目正在进行从 0 到 1 的全新架构重构与产品推演：
- 摒弃历史臃肿的技术实现，回归最纯粹的用户痛点与业务价值；
- 采用规范化的架构分层与轻量敏捷设计；
- 全流程受 GitHub Actions AI Review（DeepSeek / Kimi）质量门禁守护。
