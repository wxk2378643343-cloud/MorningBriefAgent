# MorningBriefAgent Demo

这是 MorningBriefAgent 的 Obsidian 目录示例。

这里的文件只是模板，不是用户真实数据。复制到自己的 Obsidian Vault
后，再按需调整目录和内容。

## 数据来源

- 原始文件进入 Agent 后先保留来源；
- 结构化事实写入 SQLite；
- Agent 只负责分析和编排；
- 最终结果归档到对应目录。
