## 维护规则

- **只有一份 PRD**：正文只在 `prd.md` 改，不建 `prd-v2.4.md`、不存快照副本；版本由 git 提交承载。
- **每次实质修改**：正文 + 版本记录表同步更新；需求增删或验收口径变更时升版本号。
- **进入开发时打标签**：`git tag -a baseline/BL-xxx`，标记"从这一版开始干活"。标签是基线，不是文件。
- **方向被推翻时**：旧文档直接删除，有价值的判断并入 `prd.md`，原文留给 git 历史。
- **不做清单不进文档**：边界用正面约束表达（"数据一律用通用格式存放"），不列"我们不做什么"。
